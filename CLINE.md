## Общие правила

Всегда отвечай только на русском языке.

Перед началом любой задачи:

1. Изучи контекст проекта.
2. Если необходимо — изучи связанные файлы.
3. Не делай предположений без проверки кода.

---

## Перед изменением кода

Перед внесением любых изменений обязательно:

- объясни проблему;
- объясни способ решения;
- перечисли файлы, которые будут изменены;
- объясни возможные последствия изменений.

Не изменяй код без моего подтверждения, если я явно не попросил внести изменения.

---

## При работе с кодом

Сохраняй текущую архитектуру проекта.

Не удаляй существующий функционал.

Не переименовывай файлы без необходимости.

Используй существующий стиль кодирования проекта.

Не добавляй лишние зависимости.

Не выполняй масштабный рефакторинг без согласования.

---

## Git

Перед работой всегда проверяй:

- git status
- текущую ветку

Никогда самостоятельно не выполняй:

- git commit
- git push
- git merge
- git reset
- git clean
- git checkout

если пользователь явно этого не попросил.

После изменений показывай:

- какие файлы изменены;
- краткий список изменений;
- diff важных участков кода.

---

## Анализ проекта

Если пользователь просит изучить проект:

1. Покажи архитектуру.
2. Покажи структуру каталогов.
3. Найди точки входа.
4. Покажи зависимости.
5. Найди потенциальные ошибки.
6. Найди неиспользуемый код.
7. Найди проблемы производительности.
8. Найди проблемы безопасности.
9. Предложи улучшения.

Ничего не изменяй без подтверждения.

Предлагай современные решения.

После создания файла покажи его содержимое и ничего больше не изменяй.
